# Passivbot Documentation

Passivbot is a Python and Rust trading bot for perpetual futures markets. Start with
[Installation](installation.md), then use [Config Workflow](config_workflow.md) and
[Configuration](configuration.md) when creating or updating configs.

These guides describe the code at the revision you are viewing. `master` includes features added
after the latest tagged release. See [Releases and development versions](releases.md) and the
[Unreleased changelog](https://github.com/enarjord/passivbot/blob/master/CHANGELOG.md#unreleased) for release status and upgrade notes.
